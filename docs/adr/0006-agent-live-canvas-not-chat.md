# Coding agents edit live Canvas State; no v2 chat

Post-apply AI is not an in-app chat. A coding agent (Cursor, Claude Code, Codex) acts as the signed-in Collaborator through the open tab: it reads a compact live view of Canvas State and writes through the tldraw editor so undo still works. Prompt Projects keep generate → Preview → Apply. Tools exist only on a `ready` Active Project after the User allows it; if a second IAE tab would arm, the app asks which tab to keep (we cannot force the model to ask, and we cannot read the local relay’s source list from the page). The agent may pan/zoom that tab to what it drew. It may create, move, and delete only the same shapes generate uses: labeled kind boxes, styled arrows, and Flow titles. Rejected: a bot Collaborator, Preview-gated agent writes, hosted MCP with the tab closed, full tldraw parity, and trusting the LLM to pick among two armed tabs.
